## Resumo dos Conceitos Praticados #
Durante as atividades, aprendi conceitos básicos de JavaScript, principalmente sobre variáveis, tipos de dados e manipulação de strings. Aprendi a diferença entre `let`, `const` e `var`, além de entender tipos como `string`, `number`, `boolean`, `null`, `undefined` e `object`. Também pratiquei o uso do `typeof` para identificar o tipo de uma variável, o `console.log()` para mostrar informações no console e o `prompt()` para receber informações do usuário.

As principais dificuldades foram entender alguns detalhes da linguagem, como a diferença entre `null` e `undefined`, o uso dos índices das strings e o funcionamento de métodos como `indexOf()`. Também aprendi sobre caracteres de escape, template literals e interpolação de strings. As estruturas e comandos mais utilizados nas atividades foram `let`, `const`, `typeof`, `console.log()`, `prompt()`, `indexOf()` e a notação de colchetes para acessar caracteres de uma string. Essas atividades ajudaram a melhorar minha compreensão dos conceitos básicos de JavaScript e da lógica de programação.
